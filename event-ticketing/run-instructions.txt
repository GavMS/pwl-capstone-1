# CARA MENJALANKAN PROJECT

Buka dua terminal terpisah:

0. START XAMPP

1. TERMINAL UI (Frontend/Vite):
   npm run dev

2. TERMINAL SERVER (Backend/Laravel):
   // refresh cache
   php artisan config:clear
   php artisan cache:clear
   php artisan route:clear
   php artisan view:clear
   php artisan serve

Pastikan keduanya tetap berjalan saat Anda sedang coding.
