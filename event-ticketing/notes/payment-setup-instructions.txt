# PANDUAN SETUP & PENGGUNAAN MIDTRANS PAYMENT GATEWAY (SANDBOX)

1. SETUP NGROK (EXCHANGE DATA LOCAL KE INTERNET):
   a. Download Ngrok di https://ngrok.com/download
   b. Extract file "ngrok.exe" dan masukkan ke dalam folder proyek Anda.
   c. Jalankan perintah ini di terminal baru (di dalam folder proyek):
      ./ngrok http 8000
   d. Copy alamat URL yang muncul (Contoh: https://abcd-123.ngrok-free.dev).
   e. Masukkan URL tersebut ke file .env proyek Anda:
      NGROK_URL=https://abcd-123.ngrok-free.dev

2. SETUP AKUN MIDTRANS:
   a. Daftar/Login ke https://dashboard.sandbox.midtrans.com/
   b. Masuk ke menu "Settings" -> "Access Keys".
   c. Copy "Server Key" dan "Client Key", lalu masukkan ke file .env:
      MIDTRANS_SERVER_KEY=Mid-server-xxxx
      MIDTRANS_CLIENT_KEY=Mid-client-xxxx

3. KONFIGURASI WEBHOOK DI DASHBOARD MIDTRANS:
   a. Kembali ke Dashboard Midtrans Sandbox (Website).
   b. Masuk ke menu "Settings" -> "Payment Management" -> "Notification URL".
   c. Masukkan URL berikut: https://URL-NGROK-ANDA-TADI.ngrok-free.dev/midtrans/callback
   d. Klik tombol "Update" di bagian bawah.

4. CARA MENCOBA PEMBAYARAN:
   a. Jalankan website (php artisan serve).
   b. Lakukan transaksi pembelian tiket seperti biasa.
   c. Saat muncul popup Midtrans, pilih "Bank Transfer" (Simulated) atau "QRIS/Gopay".
   d. Buka Link Simulator: https://docs.midtrans.com/en/technical-reference/sandbox-test-tools
   e. Masukkan nomor VA atau scan QR yang muncul menggunakan simulator tersebut.
   f. Jika sukses, status tiket di akun Anda akan otomatis berubah (Valid) dan email akan terkirim.

CATATAN PENTING:
- File "ngrok.exe" HARUS ada di folder proyek atau terinstall secara global.
- Ngrok HARUS menyala selama Anda mengetes pembayaran agar Midtrans bisa mengirim data ke database Anda.
